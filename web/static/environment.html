Environment

Variables for every harness. Changes apply to new sessions and explicit restarts. Existing values cannot be displayed. Saving a blank value sets an empty string.

Add or replace a variable

Names are case sensitive. Project values override global and host values. Disabling an override restores inheritance; suppression removes a variable from this project. Console identity, executable search paths and harness homes are reserved.
